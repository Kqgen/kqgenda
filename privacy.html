VyLite Studio

プライバシーポリシー

VyLite Studio(以下「この道具」)は、VyLite の作者 Kagen(以下「運営者」)が自分の TikTok アカウント @kqgenda のためだけに使う道具です。この道具が扱う情報と、その扱い方を次のとおり定めます。

1. 受け取る情報

TikTok アカウントの持ち主が TikTok の画面で許可した範囲だけを、TikTok の公式 API から受け取ります。

  • プロフィールの基本情報(open ID、表示名、ユーザー名、アイコン)
  • プロフィールの数字(フォロワー数、フォロー数、いいね数、動画数)
  • 公開している投稿の一覧と、その数字(再生数、いいね数、コメント数、シェア数など)
  • TikTok が発行するアクセストークン(上の情報を読むためと、受信箱へ下書きを送るため)

ほかの人のアカウントの情報は受け取りません。

2. 使い道

下書きを本人の TikTok の受信箱へ送ることと、本人の投稿の結果を測って次の投稿づくりに使うことだけに使います。

3. 保存のしかた

  • 受け取った情報は運営者の PC にだけ保存し、この道具のためのサーバーには送りません。
  • アクセストークンは Windows の暗号化(DPAPI)で保存し、運営者の Windows ユーザーだけが読めます。
  • 写真の下書きを送るときは、TikTok が画像を取りに来られるよう、その画像をこのサイトに置きます。置いた画像は誰でも見られる状態になります。投稿用の画像だけを置き、個人の情報は含めません。

4. ほかへの提供

受け取った情報を売ったり、ほかの人や会社に渡したりしません(法令で求められた場合を除きます)。

5. 許可の取り消しと削除

TikTok アプリの設定から、この道具への許可をいつでも取り消せます。取り消した後は新しい情報を受け取れません。保存した情報を消してほしいときは、下の連絡先へ知らせてください。

6. このページの変更

内容を変えるときは、このページを書き換えて知らせます。

English summary

VyLite Studio is used only by its operator, Kagen (the developer of VyLite), for his own TikTok account @kqgenda. With the account owner's permission it receives, through TikTok's official API, the basic profile (open ID, display name, username, avatar), profile statistics, the list and statistics of public posts, and access tokens. The data is used only to send drafts to the owner's TikTok inbox and to measure the results of his own posts. It is stored only on the operator's PC, and the tokens are encrypted with Windows DPAPI. Images for photo drafts are placed on this public website so that TikTok can fetch them. No data is sold or shared with others, except where required by law. Access can be revoked at any time in the TikTok app; for deletion requests, contact X @Kagendayo.
